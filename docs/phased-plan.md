# 合同模版生成工具 - 分期开发规划

## 总览

根据需求复杂度和技术风险，将项目分为 **3 期** 开发，每期交付可独立使用的功能。

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           分期开发路线图                                 │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  第1期（4周）          第2期（3周）           第3期（3周）               │
│  ────────────         ────────────           ────────────               │
│  核心功能              印章功能               高级功能                   │
│  ✦ 模版管理            ✦ 印章管理             ✦ 批量生成                 │
│  ✦ 单合同生成          ✦ 印章叠加             ✦ 用户权限                 │
│  ✦ 合同预览            ✦ 位置调整             ✦ 操作日志                 │
│                                                                         │
│  交付物：             交付物：               交付物：                     │
│  可生成单个合同       可盖章的合同           完整生产系统                 │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 第 1 期：核心功能

**周期**：4 周
**目标**：实现模版上传、变量填充、合同预览和导出的基础流程

### 1.1 功能范围

| 模块 | 功能项 | 优先级 | 说明 |
|------|--------|--------|------|
| 模版管理 | PDF 模版上传 | P0 | 支持 PDF 格式 |
| 模版管理 | Word 模版上传 | P0 | 支持 .docx 格式 |
| 模版管理 | 变量自动识别 | P0 | 正则提取 {{变量名}} |
| 模版管理 | 变量类型推断 | P1 | 基于关键词的启发式推断 |
| 模版管理 | 模版列表查看 | P0 | 基础 CRUD |
| 合同生成 | 变量填写表单 | P0 | 根据变量定义动态生成表单 |
| 合同生成 | 表单校验 | P0 | 必填、格式、范围校验 |
| 合同生成 | 合同预览 | P0 | 实时预览填充结果 |
| 合同生成 | PDF 导出 | P0 | 单个合同导出 |
| 前端 | 模版管理页面 | P0 | 列表 + 上传 |
| 前端 | 合同生成页面 | P0 | 表单 + 预览 |

### 1.2 技术范围

| 技术项 | 复杂度 | 说明 |
|--------|--------|------|
| NestJS 项目初始化 | 低 | 搭建基础框架 |
| Vue 3 项目初始化 | 低 | 搭建基础框架 |
| SQLite 数据库 | 低 | 模版表、变量定义表 |
| PDF 变量替换 | 中 | pdfjs-dist + pdf-lib |
| Word 变量替换 | 中 | docxtemplater |
| Word 转 PDF | 高 | LibreOffice + 进程池 |
| 中文字体支持 | 中 | 字体嵌入 |
| 坐标系转换 | 中 | pdfjs-dist ↔ pdf-lib |

### 1.3 不包含

- ❌ 印章功能
- ❌ 批量生成
- ❌ 用户登录/权限
- ❌ 操作日志

### 1.4 里程碑

| 周次 | 里程碑 | 交付物 |
|------|--------|--------|
| W1 | 项目搭建 | 前后端框架、数据库设计 |
| W2 | 模版管理 | 模版上传、变量识别、列表页 |
| W3 | PDF 合同生成 | PDF 变量替换、预览、导出 |
| W4 | Word 合同生成 + 联调 | Word 处理链、端到端测试 |

### 1.5 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| PDF 坐标系不一致 | 变量位置偏移 | 实现坐标转换函数，添加质量检测 |
| LibreOffice 冷启动慢 | 首次生成超时 | 预热机制 + 进程池 |
| 中文字体显示异常 | 合同内容乱码 | 提前准备字体文件，测试验证 |

### 1.6 验收标准

- [ ] 可上传 PDF/Word 模版
- [ ] 系统自动识别模版中的变量
- [ ] 用户可填写变量值并预览合同
- [ ] 可导出填充后的 PDF 合同
- [ ] 中文显示正常，位置基本准确

## 第 2 期：印章功能

**周期**：3 周
**目标**：实现印章上传、加密存储、叠加到合同的功能

### 2.1 功能范围

| 模块 | 功能项 | 优先级 | 说明 |
|------|--------|--------|------|
| 印章管理 | 印章上传 | P0 | PNG/JPG/SVG 格式 |
| 印章管理 | 印章列表 | P0 | 查看、删除 |
| 印章管理 | 印章分类 | P1 | 公章/合同章/财务章 |
| 印章叠加 | 自动叠加 | P0 | 叠加到指定位置 |
| 印章叠加 | 位置预设 | P0 | 右下角、左下角等 |
| 印章叠加 | 可视化调整 | P1 | 拖拽、缩放 |
| 印章叠加 | 页码选择 | P0 | 指定盖章页 |
| 安全 | 印章加密存储 | P0 | AES-256-GCM |
| 安全 | 密钥版本管理 | P0 | 支持轮换 |
| 前端 | 印章管理页面 | P0 | 列表 + 上传 |
| 前端 | 印章叠加界面 | P0 | 预览 + 位置调整 |

### 2.2 技术范围

| 技术项 | 复杂度 | 说明 |
|--------|--------|------|
| 印章图片处理 | 中 | 图片格式验证、分辨率检测 |
| AES-256-GCM 加密 | 中 | 加密/解密实现 |
| 密钥版本管理 | 高 | 数据库表 + 版本服务 |
| PDF 印章叠加 | 中 | pdf-lib 叠加图片 |
| 可视化拖拽 | 中 | 前端 Canvas/SVG 交互 |
| 坐标系映射 | 中 | 前端坐标 ↔ PDF 坐标 |

### 2.3 不包含

- ❌ 批量生成
- ❌ 用户登录/权限
- ❌ 操作日志

### 2.4 里程碑

| 周次 | 里程碑 | 交付物 |
|------|--------|--------|
| W1 | 印章管理 | 上传、加密存储、列表页 |
| W2 | 印章叠加 | PDF 叠加、位置预设、页码选择 |
| W3 | 可视化调整 + 联调 | 拖拽调整、端到端测试 |

### 2.5 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 密钥丢失 | 印章无法解密 | 环境变量备份 + 密钥导出功能 |
| 印章位置不准 | 盖章位置偏移 | 可视化预览 + 手动调整 |
| 大尺寸印章 | PDF 文件过大 | 图片压缩 + 尺寸限制 |

### 2.6 验收标准

- [ ] 可上传印章图片（PNG/JPG/SVG）
- [ ] 印章加密存储，明文不落盘
- [ ] 可选择印章叠加到合同
- [ ] 支持预设位置和手动调整
- [ ] 可指定盖章页码
- [ ] 密钥轮换后旧印章仍可解密

## 第 3 期：高级功能

**周期**：3 周
**目标**：实现批量生成、用户权限、操作日志等生产级功能

### 3.1 功能范围

| 模块 | 功能项 | 优先级 | 说明 |
|------|--------|--------|------|
| 批量生成 | Excel 导入 | P0 | 下载模版 + 上传数据 |
| 批量生成 | 手动逐条添加 | P0 | 表单逐条填写 |
| 批量生成 | JSON/CSV 导入 | P1 | 结构化数据导入 |
| 批量生成 | 批量预览 | P0 | 数据表格预览 |
| 批量生成 | 批量生成 | P0 | 后台任务执行 |
| 批量生成 | 结果打包下载 | P0 | ZIP 格式 |
| 批量生成 | 错误处理 | P0 | 失败行标记 + 重试 |
| 用户权限 | 用户登录 | P0 | 账号密码登录 |
| 用户权限 | 角色管理 | P0 | 管理员/普通用户 |
| 用户权限 | 权限控制 | P0 | 模版/印章管理权限 |
| 操作日志 | 操作记录 | P1 | 关键操作日志 |
| 操作日志 | 日志查询 | P1 | 按时间/用户筛选 |
| 前端 | 批量生成页面 | P0 | 导入 + 预览 + 进度 |
| 前端 | 用户管理页面 | P1 | 用户列表 + 角色 |
| 前端 | 日志查询页面 | P2 | 日志列表 |

### 3.2 技术范围

| 技术项 | 复杂度 | 说明 |
|--------|--------|------|
| Excel 解析 | 中 | xlsx 库 |
| CSV 解析 | 低 | csv-parse |
| 批量任务队列 | 高 | 后台任务 + 进度通知 |
| ZIP 打包 | 低 | archiver 库 |
| 用户认证 | 中 | JWT + bcrypt |
| 权限中间件 | 中 | NestJS Guard |
| 日志中间件 | 低 | 拦截器 + 数据库 |

### 3.3 里程碑

| 周次 | 里程碑 | 交付物 |
|------|--------|--------|
| W1 | 批量生成 | Excel 导入 + 批量生成 + 打包下载 |
| W2 | 用户权限 | 登录 + 角色 + 权限控制 |
| W3 | 日志 + 联调 + 优化 | 操作日志 + 端到端测试 + 性能优化 |

### 3.4 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 批量生成超时 | 大量合同生成失败 | 分批处理 + 进度通知 + 断点续传 |
| 并发冲突 | 资源竞争 | 任务队列 + 限流 |
| Excel 格式多样 | 解析失败 | 严格模版 + 校验提示 |

### 3.5 验收标准

- [ ] 支持 Excel 导入批量数据
- [ ] 可批量生成 100+ 份合同
- [ ] 生成结果可打包下载
- [ ] 用户登录和权限控制正常
- [ ] 关键操作有日志记录
- [ ] 失败任务可重试
