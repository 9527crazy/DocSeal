# 合同模版生成工具 - 需求文档

## 1. 项目背景

### 1.1 业务痛点
- **合同生成效率低**：每次签订合同都需要手动修改模版中的公司名称、金额、日期等信息
- **盖章成本高**：打印合同 → 盖章 → 扫描的流程繁琐且成本高昂
- **版本管理困难**：难以追踪合同的修改历史和不同版本

### 1.2 项目目标
开发一个自动化工具，实现：
1. 基于固定模版快速生成合同
2. 自动叠加电子印章，避免物理盖章流程

## 2. 功能需求

### 2.1 合同模版管理

#### 2.1.1 模版上传
- 支持上传 PDF 格式的合同模版
- 支持上传 Word (.docx) 格式的合同模版
- 模版中可定义变量占位符（如：`{{公司名称}}`、`{{合同金额}}`）

#### 2.1.2 变量定义
- 系统自动识别模版中的变量占位符
- 支持手动添加/编辑变量
- 变量类型：
  - 文本：公司名称、地址、联系人等
  - 数字：合同金额、数量等
  - 日期：签订日期、有效期等
  - 下拉选项：付款方式、合同类型等

#### 2.1.3 模版存储
- 模版持久化存储
- 支持模版分类管理
- 支持模版版本控制

### 2.2 合同生成

#### 2.2.1 变量填充
- 用户填写变量值
- 支持常用值记忆/自动填充
- 支持批量生成（多个合同使用不同变量值）

#### 2.2.2 合同预览
- 实时预览生成的合同
- 支持缩放、翻页查看
- 显示变量填充位置的高亮

#### 2.2.3 合同导出
- 导出为 PDF 格式
- 支持批量导出
- 文件命名规则可配置（如：`合同_{公司名称}_{日期}.pdf`）

### 2.3 印章管理

#### 2.3.1 印章上传
- 支持上传 PNG 格式的印章图片（建议透明背景）
- 支持上传 SVG 格式的印章矢量图
- 印章信息管理：名称、类型（公章/合同章/财务章等）

#### 2.3.2 印章配置
- 默认印章位置（页脚右下角等）
- 印章大小缩放
- 印章透明度调整
- 支持多页合同指定盖章页码

#### 2.3.3 印章叠加
- 自动将印章叠加到合同指定位置
- 支持手动调整印章位置
- 印章与合同内容的层级关系正确

## 3. 用户角色

### 3.1 管理员
- 管理合同模版
- 管理印章资源
- 配置系统参数

### 3.2 普通用户
- 选择模版生成合同
- 填写变量值
- 预览和导出合同
- 添加印章并导出最终合同

## 4. 非功能需求

### 4.1 性能要求
- 合同生成响应时间 < 3 秒
- 支持并发生成多个合同
- 单次批量生成支持 100+ 份合同

### 4.2 兼容性要求
- 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 支持 Windows、macOS 操作系统

### 4.3 安全要求
- 印章图片加密存储
- 操作日志记录
- 用户权限控制

## 5. 技术方案

### 5.1 技术栈
- **前端**：Vue 3 + TypeScript + Vite
- **后端**：Node.js + NestJS
- **PDF 处理**：pdf-lib / pdfjs-dist
- **模版引擎**：Handlebars / EJS
- **数据库**：SQLite (better-sqlite3)

### 5.2 核心流程

```
┌─────────────────────────────────────────────────────────────┐
│                      合同生成流程                           │
├─────────────────────────────────────────────────────────────┤
│  上传模版 → 定义变量 → 保存模版 → 选择模版 → 填写变量       │
│      ↓                                                      │
│  预览合同 → 添加印章 → 调整位置 → 导出最终合同              │
└─────────────────────────────────────────────────────────────┘
```

### 5.3 印章叠加实现

```python
# 伪代码示例
def add_stamp_to_pdf(pdf_path, stamp_image, position, page_number):
    # 读取原始 PDF
    reader = PdfReader(pdf_path)
    writer = PdfWriter()

    # 处理指定页面
    for i, page in enumerate(reader.pages):
        if i == page_number - 1:
            # 在指定位置叠加印章
            stamp_overlay = create_stamp_overlay(stamp_image, position)
            page.merge_page(stamp_overlay)
        writer.add_page(page)

    # 保存结果
    output_path = generate_output_path(pdf_path)
    with open(output_path, "wb") as f:
        writer.write(f)

    return output_path
```

## 6. 数据模型

### 6.1 模版 (Template)
```
- id: 主键
- name: 模版名称
- file_path: 模版文件路径
- variables: 变量定义 (JSON)
- category: 分类
- created_at: 创建时间
- updated_at: 更新时间
```

### 6.2 印章 (Stamp)
```
- id: 主键
- name: 印章名称
- type: 印章类型
- image_path: 印章图片路径
- default_position: 默认位置 (JSON)
- created_at: 创建时间
```

### 6.3 合同 (Contract)
```
- id: 主键
- template_id: 关联模版
- variables: 变量值 (JSON)
- output_path: 生成的合同路径
- stamp_id: 使用的印章
- stamp_position: 印章位置 (JSON)
- created_by: 创建人
- created_at: 创建时间
```
